# ArohanCare — Premier Fertility & Women's Health Clinic

A modern, high-converting, luxury landing page for **ArohanCare**, built with Vite, HTML5, Vanilla CSS, and modern web best practices.

## ✨ Features
- **Design System**: HSL color tokens (Deep Emerald `#0F4C3A`, Warm Rose `#E8A598`, Soft Gold `#D4AF37`), editorial typography (`Playfair Display`), glassmorphism, and responsive CSS.
- **Hero & Showcase**: High-res photography, primary & secondary CTAs, and floating trust cards.
- **Trust Section**: Live animated counters and clinical trust badges.
- **Conditions We Treat**: Interactive card grid with detail drawers for PCOS, Irregular Periods, Ovulation, Hormonal Imbalance, and Pregnancy Planning.
- **Doctor Profile**: Credentials, stats timeline, and appointment scheduling with Dr. Ananya Sharma.
- **Interactive Patient Journey**: 6-step progress timeline.
- **60-Second Health Assessment Quiz**: Interactive 4-step quiz calculating personalized care recommendations.
- **Testimonial Carousel & FAQ Accordion**: Real story cards and smooth toggle FAQs.
- **Conversion Flow**: Quick appointment booking modal with form validation and confetti celebration, plus an exit-intent offer.
- **SEO & Structured Data**: Schema.org `MedicalClinic` JSON-LD markup.

## 🚀 Quick Start

### Install Dependencies
```bash
npm install
```

### Run Local Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
